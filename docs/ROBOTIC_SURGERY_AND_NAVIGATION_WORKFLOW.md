# 闭环数字化手术体系：从节点规划、术中配准到机器人执行
## End-to-End Surgical Workflow: Planning → Registration → Navigation → Robotics

**文档视角：** 用户体验、临床交互流程与产品功能设计（非底层代码实现）  
**核心理念：** 节点不仅是画图工具，而是**定义整台手术的“数字化指令集”**。

---

## 1. 整体产品愿景：闭环数字化手术链 (Closed-Loop Pipeline)

传统手术规划软件最大的痛点是**“规划与执行割裂”**：
- 医生在电脑里做好了漂亮的 3D 方案，但到了手术室，只能靠肉眼看屏幕或者打印一张纸凭经验下刀。

在 NodeSurg 平台中，规划方案将**无缝向下游流动**，形成一条完整的自动化链条：

```
+-----------------------------------------------------------------------------------------+
|                                闭环数字化手术四大阶段                                   |
|                                                                                         |
|  [ 阶段 1: 手术方案规划 ]          [ 阶段 2: 配准方案设计 ]                             |
|  • 截骨平面与角度 (Slope/Varus)    • 解剖标志点拾取 (Fiducial Points)                   |
|  • 假体规格与 3D 姿态             • 表面点云采集路径 (Surface Swiping Region)          |
|  • 螺钉安全通道 (Trajectory)       • 术中 C 臂透视配准参考位姿                          |
|                 │                                  │                                    |
|                 ▼                                  ▼                                    |
|  [ 阶段 3: 生成导航系统配置 ]      [ 阶段 4: 部署到机器人平台 ]                         |
|  • 光学追踪靶标 (DRF) 标定参数     • 机械臂定位目标位姿 (Target Pose in Robot Base)     |
|  • 术中引导界面 (Crosshair 瞄准)   • 虚拟安全边界 (Virtual Fixtures / Safety Envelopes) |
|  • 关键神经/血管距离报警阈值       • 一键生成机器人执行工程包 (OpenIGTLink / ROS2)      |
+-----------------------------------------------------------------------------------------+
```

## 3. 四大阶段的用户体验与操作流程

### 阶段 1：手术方案规划 (Surgical Planning)
- **用户操作：**
  - 在 3D 骨骼模型上放置截骨板或假体。
  - 调整截骨倾角（如后倾 $5^\circ$、外翻 $3^\circ$），或规划椎弓根螺钉进针点与靶点。
- **输出成果：**
  - 骨骼坐标系下的目标几何平面、目标孔道轴线、假体空间姿态矩阵。

---

### 阶段 2：支持术中配准方案设计 (Registration Strategy)
规划再好，术中机器人不知道“患者骨骼在真实手术台上的哪个位置”。配准就是建立**虚拟模型与真实患者的一一映射**。

在 NodeSurg 中，用户在术前就能像“排练”一样设计配准策略：
1. **点对点配准设计 (Paired-Point Registration)：**
   - 用户在 3D 模型上点选 4–6 个术中切口内容易摸到的骨性突起（如内踝、外踝尖、胫骨结节）。
   - 节点自动计算**配准敏感度与误差预测 (TRE 预估)**，如果用户选的点过于集中，节点会闪烁黄色警告：*“点位过于集中在前方，建议在侧方增加一点以提升旋转配准精度”*。
2. **表面划动采点区定义 (Surface Swiping Region)：**
   - 医生用虚拟画笔在骨面涂抹一块绿色区域，作为术中探针划动采点（ICP 配准）的推荐区域，避开软组织遮挡区。
3. **透视 2D-3D 配准预演 (Fluoro-to-CT Registration)：**
   - 针对创伤或微创手术，系统预先生成虚拟正侧位透视投影图（DRR），术中 C 臂拍两张片子即可自动对齐。

---

### 阶段 3：生成导航系统 (Navigation Runtime Generation)
配准规划好之后，用户点击连接到 `[导航生成节点]`：
1. **光学/电磁追踪靶标配置 (Tracking Marker Config)：**
   - 设定固定在患者骨骼上的动态参考架（DRF 跟踪夹具）与探针工具的几何标定文件。
2. **术中引导界面预设 (Surgeon HUD Layout)：**
   - 用户可以预设进入手术室后导航屏幕显示什么：
     - 瞄准十字线 (Bullseye Crosshair)：辅助医生将钻头对准进针轴线。
     - 深度计 (Depth Gauge)：进钻距离目标深度还剩多少毫米。
     - 角度偏离指示器：当前工具姿态与规划轴线相差多少度（如 $<1^\circ$ 为绿色，$>2^\circ$ 变为红色警告）。

---

### 阶段 4：部署到机器人平台 (Robotic Execution)
当手术方案通过主任医生审核后，直接下发到手术机器人（如机械臂骨科手术机器人）：

1. **虚拟夹具与安全边界 (Virtual Fixtures / Safety Boundary)：**
   - 机械臂并不是盲目运动，而是受“软屏障 (Active Constraints)”保护。
   - 系统根据规划的截骨厚度，自动生成一个**限制盒 (Safe Workspace)**：
     - 机械臂只能在规划的平面内摆动铣削。
     - 一旦医生推动机械臂接近后方血管神经区，机械臂电机主动产生**反向阻尼排斥力 (Haptic Feedback)**，物理上阻止越界！
2. **机器人目标位姿转化 (Kinematic Target Generation)：**
   - 系统自动将手术平面的坐标系转换成机器人基座坐标系可识别的六自由度目标位姿。
3. **一键生成部署包 (One-Click Export)：**
   - 支持医疗行业通用通信标准：
     - **OpenIGTLink**（国内外主流手术导航与机器人开源通信协议）。
     - **ROS2 控制工程包**（针对采用机械臂底层的研发团队与机器人平台）。
     - **标准化 JSON / DICOM RT Plan**（供商业导航台车直接读取）。

## 4. 医生与工程师的协同体验

```
+-----------------------------------------------------------------------------------------+
|                                    术前到术中流转体验                                   |
|                                                                                         |
|   【办公室 / 电脑前】                                                                   |
|   1. 临床工程师搭建好完整节点图（规划 + 配准方案 + 机器人安全区）                       |
|   2. 主任医生在简洁界面上微调截骨角度并点击【核准方案】                                 |
|   3. 系统生成《数字化手术工程包》（包含：3D解剖、配准清单、机器人路径、导航布局）       |
|                                                                                         |
|   【手术室内 / 机器人台车】                                                             |
|   4. 登录网页端或局域网台车，一键载入该患者工程包                                      |
|   5. 探针依次轻触预设配准点 ──> 绿灯亮起，配准误差 0.3mm (通过)                        |
|   6. 机器人机械臂自动运动到规划截骨截面，锁定姿态，进入安全铣削模式                     |
+-----------------------------------------------------------------------------------------+
```

## 5. 对用户的核心价值总结

| 传统手术流程痛点 | NodeSurg 闭环方案带来的改变 |
|---|---|
| **“规划是一套，导航又是一套”** | 规划数据与导航、配准参数原生互通，无需在不同软件间反复导入导出。 |
| **“术中配准全靠手感试错”** | 术前可视化规划最佳配准点与推荐采点区，系统提前预估配准精度与风险。 |
| **“机器人编程门槛高，参数易出错”** | 节点自动将解剖平面与螺钉轴线转化为机械臂能够理解的坐标位姿与虚拟阻尼安全区。 |
| **“无法跨硬件平台复用”** | 节点式架构将“手术算法”与“机器人底层”解耦，一套规划方案可以输出给不同品牌的机械臂或导航仪。 |
